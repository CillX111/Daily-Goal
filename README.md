# Habit Kalender

**Ein Ziel, ein Kalender, jeden Tag ein Klick: geschafft oder nicht.**

Setz dir ein tägliches Ziel und hak jeden Tag ab. Der Kalender zeigt dir, wie dein Monat läuft und wie lang deine Serie (Streak) gerade ist.

## Funktionen

- 🎯 Eigenes Ziel festlegen
- ✅ Tag anklicken → *Erreicht* oder *Nicht erreicht* (auch mehrmals nicht geschafft zählbar)
- 🔥 Streak-Zähler
- 📊 Fortschritt pro Monat: erreicht, nicht erreicht, offen
- ‹ › Zwischen Monaten blättern, Monat zurücksetzen

## Benutzen

`index.html` im Browser öffnen. Alles wird lokal im Browser gespeichert (localStorage) – kein Konto, kein Server.
